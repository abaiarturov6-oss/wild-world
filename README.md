# Дикий мир

Небольшой двуязычный сайт о животных на русском и кыргызском языках.

## Публикация на GitHub Pages

Репозиторий публикуется автоматически через GitHub Actions после отправки изменений в ветку `main`.

1. Создайте публичный репозиторий на GitHub.
2. Загрузите содержимое этой папки в корень репозитория.
3. В настройках репозитория откройте **Pages** и в разделе **Build and deployment** выберите **GitHub Actions**.
4. Отправьте файлы в ветку `main`. После успешного запуска workflow сайт будет доступен по адресу `https://<имя-пользователя>.github.io/<имя-репозитория>/`.

Файл сайта: `index.html`.
